# 跨境指挥台 Commander · 多店铺亚马逊运营中心

纯前端单页应用（SPA），面向同时运营多家亚马逊店铺的跨境卖家，支持多店铺、美/欧/日多站点、不限定单一类目。

## 核心理念

- **系统负责记录节点、汇总数据；人负责业务判断。先风险，后经营。**
- **不上云、无后端**：所有数据保存在浏览器 IndexedDB，不调用亚马逊 API、不爬虫。
- **数据手动录入 / 本地 CSV 导入**，支持 JSON 导出备份。

## 功能结构

左侧 6 大业务分组，共 21 个页面：

| 分组 | 页面 |
|---|---|
| 总览 | 店铺总览、风险清单 |
| 节奏 | 每日巡店、大促时间表、待办事项 |
| 诊断 | 诊断中心（广告/利润/Listing/库存/账户） |
| 经营 | 店铺与站点、产品与成本、每日数据录入、Listing 工作台、广告管理、库存与履约、退货与索赔、促销台账 |
| 选品库 | 选品立项、竞品追踪、关键词词库、合规中心 |
| 设置 | 数据导入、数据与备份、设置与阈值 |

## 技术栈

- 原生 HTML / CSS / JavaScript（无构建步骤）
- [ECharts](https://echarts.apache.org/) 本地化引入（`vendor/echarts.min.js`），断网可用
- IndexedDB 浏览器本地存储

## 本地运行

因部分浏览器在 `file://` 协议下禁用 IndexedDB，建议用本地静态服务打开：

```bash
cd commander
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

## 数据说明

- 首次打开自动写入演示数据，可在「数据与备份 → 重置为演示数据」清除。
- **数据仅保存在当前浏览器**，换电脑或清缓存前请务必「导出 JSON」备份。
