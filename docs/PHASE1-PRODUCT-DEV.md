# Phase 1 · 选品开发模块重构 — 需求拆解与清单（现状评审）

> **模块**：亚马逊跨境卖家工作台 Commander · 选品开发
> **阶段**：Phase 1（现状评审 & 需求拆解，不做代码、不做架构）
> **输入**：`excel_summary.md`（15 个 Excel 模板结构抽取）、现有 `mod-assets.js` / `app.js` / `db.js` / `ui.js`
> **约定**：业务逻辑/字段定义/利润公式/调研流程须交跨境电商专家确认，不能脑补；UI/导出/IndexedDB 由研发处理。
> **UI 风格**：沿用 Commander 科技蓝（`#1E5FA8` 主色），复用 `.card / .toolbar / .nav-*` 与 `U.table / U.card / U.empty / U.modal / U.formFields / U.exportCSV / U.tag / U.money / U.pct`。

## 一、页面清单（3 个路由页）

原「选品开发」子菜单有 3 个扁平项：`selection`(选品立项)、`competitors`(竞品调研)、`profit`(利润测算)。
Phase 1 将其改造为 **3 个独立路由页**，每项降/升为页 + 内部 Tab，不再单建页面、也不硬塞一页。

| 路由 key | 页面标题 | 对应原菜单项 | 处理建议 | 备注 |
|---|---|---|---|---|
| `dev-selection` | 选品立项&市场调研 | `selection`（选品立项） | 原 `selection` 页降级为 **Tab1 选品立项**（保留六维评分逻辑），并入市场调研类 Tab | 整合最重，含 4 个 Tab |
| `dev-competitor` | 竞品深度分析 | `competitors`（竞品调研） | 原 `competitors` 页重组为 **3 个 Tab**（基础表/多维度/调研&推广计划），保留快照录入逻辑 | 竞品快照时间序列建议并入 Tab1 |
| `dev-profit` | 利润测算&产品开发 | `profit`（利润测算） | 原 `profit` 页重组为 **4 个 Tab**（利润测算/核对表/利润指标/通用分析/开发表） | `star:1` 建议保留在 `dev-profit` |

> 菜单项沿用现有 `MENU` 结构，仅改 `k/t` 与目标页；三页仍挂在「选品开发」分组下。
